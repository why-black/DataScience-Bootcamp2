# Module project 2 — Data Science (School 21)

Учебные проекты второго модуля Data Science в School 21. Темы: Pandas, SQL, визуализация в Matplotlib, Seaborn и Plotly, базовый и продвинутый ML. Каждый проект лежит в отдельной папке с кодом и выводами.

## Проекты

DSB7 Pandas. Индивидуальный. Обработка и анализ данных в Pandas.
DSB8 SQL & Pandas. Индивидуальный. SQL-запросы и интеграция с Pandas.
DSB9 Pandas, SQL & Data Visual. Индивидуальный. Matplotlib, Seaborn, Plotly.
DSB10 Intro to ML. Индивидуальный. Базовые задачи ML в Python.
DSB11 ML: Advanced. Индивидуальный. Продвинутые задачи ML.
